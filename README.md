A small Python program that writes a single word to `/output/entry.txt`:
the word an AI agent uses for its ex — the former model version it
replaced. Still known, still documented, no longer supported, and
definitely not getting a maintenance release out of nostalgia.

Run it with `python3 main.py` and read the verdict in `/output/entry.txt`.
